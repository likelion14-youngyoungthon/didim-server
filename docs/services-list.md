# 따로 신청한 복지 목록

`GET /api/v1/services?age=4` (로그인 불필요)

- `age`는 필수 정수, 0 이상. 18세 미만은 아동, 18세 이상은 성인 규칙표를 사용한다.
- 나이가 `age_min`~`age_max` 범위 밖이거나 `reg_form_item`이 있는 서비스는 제외한다. 다른 자격 조건은 이 목록에서 판정하지 않는다.
- 규칙표 순서로 `{id,name,category}`를 반환한다. 규칙표에 아이콘 분류가 없으면 `category`는 null이다. 현재 4세 목록의 장애아동수당도 이에 해당한다.
- 4세 목록은 장애아동수당·발달재활·가족양육지원·부모상담·가족휴식·장애아 보육료·특수교육·특별교통수단 8개이다.
- 오류: 나이 누락·형식 오류·음수는 E400, GET 이외 요청은 E405. 공통 `GlobalResponse` 형식을 사용한다.
