# 판정 응답의 온라인 신청 표시

- `POST /api/v1/judge`의 각 서비스에 `online: boolean`을 추가한다.
- 규칙표 `office_note`에 `복지로 온라인`이 명시된 경우에만 `true`이다. 18세 미만은 발달재활 1종, 성인은 장애인연금 2종·장애수당·활동지원·주간활동·보조기기·자립자금대여·에너지바우처 8종이다.
- `false`는 해당 규칙표에 복지로 온라인 신청 근거가 없다는 뜻이며, 모든 온라인 경로가 불가능하다는 뜻은 아니다.
- `basis.sources[0]`은 복지로 **지원정보 상세 페이지**이다. 실제 온라인 신청서 주소로 안내하지 않는다.
- 요청·오류 형식은 기존 `/judge` 계약과 같다.
